# Rock Paper Scissors

A browser-based Rock Paper Scissors game built with **HTML, CSS, and JavaScript**.

## 🎮 Features

* Choose Rock, Paper, or Scissors
* Computer generates a random choice
* Displays both player and computer choices
* Tracks player and computer scores
* Shows the result of each round
* Responsive design for smaller screens
* Interactive hover effects

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🧠 What I Practiced

* DOM manipulation
* Event listeners
* Functions
* Conditional logic
* Random number generation
* Updating the UI dynamically
* Managing game scores

## 🎯 Purpose

This project was created to practice JavaScript logic, DOM manipulation, and event handling while building a simple interactive browser game.
